# 素材

| 資料夾 | 內容 |
| --- | --- |
| `audio/` | 網站使用的 128 kbps 背景音樂，清單見 `docs/AUDIO-ASSETS.json` |
| `models/` | 3D 模型；`*-web.glb` 是網站載入的壓縮版，其餘是原檔，供重新產生與測試比對 |
| `fonts/` | 字型與授權檔 |
| `illustrations/` | 插畫與 SVG |

音樂原檔放在 `assets/` 根目錄。`illustrations/` 內有些 PNG 網站已不載入，但仍有測試比對雜湊，刪除前要一併處理清單與測試。

新增圖片要提供合適的 alt，裝飾圖片使用空 alt。
