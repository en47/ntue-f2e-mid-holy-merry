# 素材預留

已接入提供的聖誕老人 GLB：`models/santa-claus.glb`，檔案資訊見 `models/santa-claus.json`。首頁使用本機檢視元件顯示原模型，未重畫或替換角色。其他素材請放入對應資料夾：

| 資料夾 | 預留內容 |
| --- | --- |
| illustrations | Logo、首頁主視覺、聖誕由來、角色、樹、禮物 |
| maps | 自繪世界地圖 |
| fonts | 有使用授權的手寫字體 |
| audio | 有使用授權的背景音樂 |
| models | Santa / Reindeer GLB、GLTF 及相關貼圖 |

替換入口與操作方式見專案根目錄 `README.md`。新增圖片需提供合適的 alt；裝飾圖片使用空 alt。
