## 觀察

- 手機效能分數偏低的主因是主執行緒被佔用（TBT）：首頁 8,422ms、Wish 2,609ms、Game 1,353ms。3D 模型解析與紙雕轉成圖片都在主執行緒上進行。
- Game 手機版 LCP 16.1s、下載量 8.23MB，主要是兩款遊戲的原圖（配對遊戲卡片圖約 6.5MB）。
- 首頁手機版 CLS 0.146，超過 0.1 的建議值，版面在載入時有位移。
- Intro 是最好的範例：只有 0.19MB，手機效能 98 分。
- 最佳做法與 SEO 四頁都是 100。

## 扣分項目

- 無障礙：導覽標語 `.brand-small`（`#667d85` 配 `#c7e3ec`，3.23:1）與 Game 兩款遊戲的說明文字（`#667d85` 配 `#dfeef3`，3.65:1）對比不足 4.5:1；Wish 的 `.room-sky` 設了 `aria-hidden`，裡面卻有可取得焦點的元素。
- 效能：主執行緒工作量與 JavaScript 執行時間（Home、Game、Wish）、JavaScript 未壓縮與未使用（Game、Wish）、Game 圖片、四頁的阻擋算繪請求，以及快取期限（GitHub Pages 固定 `max-age=600`，網站無法調整）。
