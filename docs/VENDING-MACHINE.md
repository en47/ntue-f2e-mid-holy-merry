# 紙雕聖誕拉霸販賣機

2026-11-24：第五頁的販賣機改成 1930 年代拉霸機輪廓的紙雕機器。使用者看過提案後選定：出貨用「紙幕剪影」，按鈕用紙按鈕。機器本體全部用 Three.js 程式疊卡紙（`js/components/vending-papercraft.js`），只有四個商品還是 Tripo3D 的模型（`docs/VENDING-MODELS.md`）。華麗感來自對稱的 Art Deco 造型（放射線、階梯、拱形、雙金線）和紙板層次，不靠發光，也不用金屬反光。

## 比例

以機身寬為 1（場景裡機身寬 0.5，所有尺寸在 `MACHINE`）。總高約 2.53；加上拉到最遠的拉桿，總寬約 1.56。

| 區塊 | 高度 | 內容 |
| --- | --- | --- |
| 招牌 | 28% | 紅色半圓、13 道奶油色與淡金色放射紙條、雙層金框、11 顆小燈泡、階梯形酒紅標題板、CHRISTMAS VENDING 立體紙字、兩肩積雪、左肩冬青、頂上星星 |
| 展示櫃 | 32% | 金框、深綠底板、4 個拱形格（寬 0.36、高 0.34）；每格有奶油色展示台、上方的暖光、從上方滑下的展示門 |
| 按鍵板 | 11% | 奶油色底板、凸起的金邊、兩側各三條金線、2×2 紙按鈕（位置跟四格一樣，圖示來自著色桌的線稿） |
| 舞台 | 25% | 往前凸 0.08 的台口（金色正面）、扇貝邊的帷幕上緣、兩片半透明紅紙幕、後面的背光紙、木紋地板、會往前推 0.08 的托盤 |
| 底座 | 4% | 兩階松綠色階梯、腳邊積雪 |

- 機身深 0.42：招牌只有正面一片（厚 0.12）；展示格往內凹 0.2；舞台內部深約 0.37。
- 商品高 0.26。薑餅人最寬（寬高比 0.79）也最薄（厚度只有高度的 0.17），格寬照它決定，轉身最多轉約 15°，不會露出 Tripo 生成的背面。
- 拉桿：轉軸在機身右側外 0.07 的支架上，桿長 0.34。它跟正面平行轉，從 1 點鐘拉到 5 點鐘（120°），所以從正面看整段路徑都在機身外面，不會被擋住。五顆燈泡沿著握把走的弧線排在半圓形的綠色扇板上。
- 鏡頭：正面、略高一點，取景範圍是「機身＋拉到最遠的拉桿」（`MACHINE.bounds`）。手機上舞台區從 540px 提高到 600px。

## 互動

邏輯在 `js/services/vending-lever.js`（純函式，`tests/vending-lever.test.mjs`），畫面在 `js/components/vending-machine.js`。

- 狀態：待機 `idle`（拉桿扣著）→ 已選 `chosen` → 拉動中 `pulling` → 出貨中 `running` → 等你拿 `ready` → 拿走後回到 `idle`。
- 選擇：按鈕先沉到底，再回到半沉的位置停住（像老收音機的選台鍵），原本選的那顆彈起來；那一格變亮、其他三格變暗；商品跳一下、左右轉一點；第一次選時拉桿的卡榫「喀」一聲鬆開，握把點一下頭。
- 拉桿：拖曳時用握把相對轉軸的角度算拉了多少。每 20% 亮一顆燈，亮度在那一段裡慢慢變滿，滿的時候輕輕跳一下、響一個音（C5、D5、E5、G5、C6）。往回拉就依序變暗。拉過 92% 自動吸到底。
  - 沒拉到底就放開：拉桿彈回、燈依序熄掉，不出貨。
  - 只點一下沒拖：拉桿點一下頭。
  - 還沒選就拉：卡榫擋住，拉桿只動一點就彈回，四顆按鈕依序浮一下。
- 鍵盤：Tab 到按鈕按 Enter 選。拉桿是 slider：方向鍵一次 20%，Enter 或空白鍵放開（還沒到底就自動拉到底再放開）；拉到一半離開焦點會彈回。這是「不能點一下就播動畫」唯一的例外。
- 熱區：按鈕、拉桿、舞台各疊一個 HTML 元素。拉桿的熱區設 `touch-action: none`，手機上拖拉桿不會捲動頁面；按鈕的熱區不超過按鈕之間的距離，不會互相重疊。
- 讀屏軟體會聽到每一步（選了什麼、拉桿還扣著、彈回去、出發、到舞台上），畫面上不出現提示字。

## 出貨（放開拉桿後，`DELIVERY`，毫秒）

| 時間 | 發生什麼 |
| --- | --- |
| 0～380 | 拉桿回彈，稍微超過原位再停好；輪轂齒輪開始轉（一直轉到結束） |
| 50～650 | 機身輕震三下 |
| 200～650 | 那一格的展示門落下、暖光熄掉；門關上後，商品換成深色材質（剪影），壓扁貼在舞台最後面的背光紙前、舞台上方（被機身正面擋住，看不到） |
| 600～1000 | 紙幕後面的燈亮起，紅紙幕透出暖光 |
| 1000～2100 | 剪影在幕後慢慢降下，落地輕輕彈一下（像皮影戲，影子是一個扁平清楚的形狀） |
| 2100～2500 | 叮一聲，燈慢慢熄掉，紙幕又變暗 |
| 2500～3050 | 紙幕俐落地往兩側拉開再慢慢停住，舞台燈亮起；拉開 90 毫秒、縫夠寬時，商品換回原本的樣子站到托盤上（兩片幕在中間重疊、下緣略低於地板，關著時看不到幕後） |
| 3050～3450 | 托盤推出，雪地上多一片暖光 |
| 3450～3950 | 商品轉身面向你，鈴聲；之後每 3.2 秒輕輕晃一下 |
| 700～2700 | 五顆燈每 0.5 秒熄一顆 |

- 商品在舞台上時，可以直接按另一顆按鈕換一個：舞台燈熄、托盤收回、商品縮回原大小，紙幕關上；幕後商品回到自己那一格，展示門升起、暖光回來、按鈕彈起；接著選起新的那一個（約 1.4 秒），再拉一次拉桿出貨。按同一顆按鈕沒有反應。狀態流程是 `ready → change → returning → back → idle`，然後是新的選擇。
- 點舞台拿走商品：著色桌從托盤的位置展開。著色桌蓋住機器時一次放回原狀：商品回展示台、展示門升起、紙幕關上、托盤收回、按鈕彈起、拉桿扣回、燈全熄。
- 減少動態：拉桿照樣能拖；出貨直接跳到結果，只響最後的鈴聲。
- 只在有東西動時重畫。招牌燈泡的光暈是疊在畫布上面的 CSS（慢慢明暗），不必讓 3D 一直重畫。

## 材質與光

- 紙板：`MeshLambertMaterial` 加紙纖維顆粒貼圖，不經過色調映射（顏色照原樣）；每片卡紙正面和切邊兩種顏色，層與層之間有柔和的影子。
- 商品：照 Tripo3D 的樣子（霧面、ACES 曝光 0.5、各自的攝影棚環境光），見 `docs/VENDING-MODELS.md`。
- 燈：天光、左前方主光（柔和陰影）、背後冷色輪廓光；舞台亮起時多一盞暖色聚光燈。
- 地面影子：`ShadowMaterial` 加一段往外淡出的著色器，影子不會在地面的邊界切出硬邊。
- 展示門用剪裁平面藏住超出窗口的部分；紙幕是場景裡唯一的大片半透明物件，背光紙、剪影、商品都在它後面。
- 招牌的字是頁面標題字型（Mountains of Christmas）的輪廓擠出成卡紙，由 `scripts/build-title-glyphs.mjs` 產生 `js/data/marquee-glyphs.js`（不要手改）。
