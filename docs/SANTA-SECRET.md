- 拿掉這兩條規則，答案就不止一組。

## 兩次反轉

### 第一次反轉

- 交接表補對的那一刻成立（`knowsSantas` 只看交接表）。
- 接著聖誕老人說明秘密，存成 `story.told`：
  - 他還在外面：從門外回來。
  - 他已經在屋裡：從搖椅上說。
- 說明時他翻開小冊黏住的後半本「替身守則」。之後登記簿最下面一格才能簽。

### 舊紀錄簿：開啟和理解分開

- 一進小房間就能轉，轉到 2003 就打開（`finale.unlocked`）。不需要加入，也不需要工作章，原本「兩個章才解得開」的門檻（`canUntie`）已經拿掉。
- 內容：
  - CHRISTMAS RECORD · 024：荷莉的願望、WISH FULFILLED、2003/12/24。
  - 見習與夜班的紀錄。
  - 鉛筆字。
  - 親筆便條（英文附中文）。
- 打開後讀不讀得懂，看交接表補對了沒有：
  - 補對以後才讀：理解第二次反轉（`finale.twist`）。
  - 補對以前就讀：只讀得懂表面，「夜班是什麼？」

### 四種發現順序

| 順序 | 結果 |
| --- | --- |
| 先補交接表，再開舊紀錄 | 讀完就理解 |
| 先開舊紀錄，再補交接表 | 聖誕老人說明時加一句「現在再讀一次，說不定會讀出不一樣的東西」，舊紀錄簿書角發光；再翻一次（不用再轉密碼）才理解 |
| 補好交接表，一直不開舊紀錄 | 主線照常，可以加入；結局是一般版 |
| 加入前就開過，加入後拿到空白紙條 | 紙條照樣烤得出字，字幕改成「雪花球記得的那一年……你已經知道了。」 |

## 其他

- **荷莉的帽子**：最小的帽子隨時都翻得開，拿到荷莉的見面禮，不用再先讀舊紀錄。內側的繡字要用放大鏡才看得清：「H. 2003」。
- **空白紙條**：紅繩不在登記簿上了，所以加入後，紙條改夾在登記簿你那一列。熱源和放進口袋，等第 5 階段再改。
