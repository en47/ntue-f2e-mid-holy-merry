## 設計及分層

主要參考為使用者提供的 `christmas_pop_up_demo_v4_handdrawn.html`，七張 PNG 全部來自 `christmas_papercut_assets.zip`，逐位元組核對且沒有重繪、壓縮或裁改原檔。來源雜湊見 `STORYBOOK-ASSETS.json`。

首頁延續 V4 的粉藍天空、奶油紙邊、紅綠手繪標題、鉸鏈開場及柔和紙雕陰影。圖層順序為天空 → 山景 (z1) → 雲 (z2) → 村落 (z4) → 透明角色 Canvas (z7) → 角色操作區 (z8) → 雪景及松樹 (z11–12) → 手繪標題 (z13) → 按鈕 (z15) → 紙紋 (z20，禁止攔截事件)。

低矮雪堆特別放在角色前方，局部蓋住腳尖；松樹框住兩側，中央保留互動空間。圖片裝飾 `pointer-events: none`，控制列位於插畫上層。山、村落、前景及樹木使用 `perspective() rotateX()` 由底部鉸鏈展開並稍微回彈，最後標題入場輕搖。約四秒完成，不等待大型 GLB；「重播開場」只重播紙雕，避免重新下載模型。

1440px 使用寬舞台，768px 調整山景及角色佔比，390px 放大背景紙景並精簡側邊樹木；兩隻角色維持並排。保留四頁導覽、即時倒數、音樂控制及 Footer。

## 模型與動畫

- 新 Santa：`assets/models/santa-dance.glb`，來源 `santa+claus+figurine+3d+model.glb`，9,790,216 bytes。內含 `dance_02`（約 12.792 秒、24fps）。舊 `santa-claus.glb` 留存但不載入，也不作為失敗替代。
- 麋鹿：繼續使用 `assets/models/reindeer.glb`，沒有複製另一份或替換模型。原 `preset:quadruped:walk` 留在未修改 GLB 內，但首頁不播放。
- `character-animation.js` 的 `sliceSantaDance()` 在原插值器取精確 1.000 / 4.000 秒姿勢，保留區間內所有關鍵影格及原始 STEP / LINEAR 插值，平移時間為 0–3 秒。來源 24fps 等同第 24–96 幀，包含兩端。未使用會排除 endFrame、遺失常數軌跡的直接 subclip 寫法。
- Santa 只對三秒片段使用 AnimationMixer / LoopRepeat。第 4 秒與第 1 秒並非一致姿勢（例如左小腿旋轉相差約 95°），因此 `softenSantaLoop()` 在每次循環後的 0.18 秒，混合原第 4 秒端點與原第 1 秒起的姿勢，降低瞬間跳接。週期仍是三秒；不修改原關鍵影格、不引入範圍外姿勢，不加入轉身、扭轉或其他舞步。這是明確的播放混合，不宣稱原片段天然無縫。將 seconds 設為 0 可檢視未混合的硬接。
- 麋鹿確有可用骨架：`tripo0_Left/Right_Limb_0–3` 是前腿，`tripo1_Left/Right_Limb_0–3` 為後腿，另有 `Spine_1`、`Head_0`、`Root`。從 inverse bind matrices 恢復原綁定姿勢，新增四秒 `storybook:reindeer-dance`。前腿交替使用 0.10 / −0.35 / 0.20 rad 的保守旋轉、前半身輕搖、頭部點頭，最後才原地小跳；不變更骨長、scale 或網格。
- 解析真實骨架測試確認：抬前腿期間兩個後腳端點保持固定（誤差 < 0.000001 原模型單位），前蹄約抬起 1cm；最後小跳約 0.008 模型單位。前後端姿勢相同，可循環。這是專為目前骨架寫的舞步，不是通用自動重定向或完整 IK；未來換骨架時需重新檢查。

## 相機、互動及效能

沿用一個 Renderer、多 scene / mixer / camera 的基礎，將 Canvas 改為相對紙雕舞台定位。從舞台及槽位的 DOM 座標換算 viewport / scissor，視窗調整或捲動時同步更新。兩個角色共用世界尺度及地面投影；動畫包絡只在載入時取樣一次，以外層群組置中、等比縮放及對齊，不逐幀拉回腳部。

材質與貼圖原樣保留，使用柔和暖色主光、環境光、接觸陰影，沒有 bloom、材質強制替換或新模型。DPR ≤ 1.5，手機最高 30fps；離開可見範圍或分頁時暫停重繪。離頁清理 RAF、觀察器、事件、Mixer、端點混合 Action、貼圖、骨架與 GPU 資源，快取返回後重新初始化。

左右拖曳／方向鍵旋轉、放開回正；手機 `touch-action: pan-y` 保留直滑捲動。角色槽有 button 語意，Enter / Space 說話，也提供獨立的小紙標籤按鈕。Santa 從左、麋鹿從右滑入小型對話泡泡，隨機使用既有陣列且避免連續相同；一次只顯示一個，五秒後收起，亦可點擊關閉。讀屏使用獨立 live region。減少動態設定會停用紙雕／標題／對話過場並預設暫停角色，仍可由使用者明確播放。

實體手機、多瀏覽器與低階手機效能仍需實機驗收。Santa 的接點混合降低跳接，但原片段兩端姿勢差異大，不保證達到重新製作循環動作的連續程度；未更動使用者指定片段。詳細階段紀錄見 `TESTING.md`。另實際確認 Santa 可獨立暫停／播放、Intro 連結成功且返回首頁後兩模型重新初始化。
