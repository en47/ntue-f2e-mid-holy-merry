# Santa 解謎試玩記錄表（第七階段）

給 2～3 位**沒玩過**的人實際玩一次，量每章花多久、卡在哪裡、用了幾次提示。設計目標：第一次完整遊玩約 40～45 分鐘（`docs/SANTA-PUZZLE-DESIGN.md` 開頭），熟手約 30 分鐘。

## 開始前

1. 在這台電腦開網站：`python3 -m http.server 5500 --bind 127.0.0.1`
2. 用瀏覽器的**無痕視窗**打開 `http://127.0.0.1:5500/santa.html`。無痕視窗沒有舊存檔，每位試玩者都從頭開始。
3. 手機試玩：手機和電腦連同一個 Wi-Fi，伺服器改用 `--bind 0.0.0.0`，手機用無痕分頁開 `http://電腦的區網 IP:5500/santa.html`。
4. 只跟試玩者說：「這是聖誕老人的小屋，自由探索，右上角的筆記本有提示。」其他什麼都不說，也不要幫忙點。
5. 旁觀的人準備碼錶，照下表記下每章**開始**的時間。

## 每章從什麼時候算起

| 章 | 開始的時刻（畫面上看得到的事） |
| --- | --- |
| 一　院子 | 頁面載入完成，看到小屋前的院子 |
| 二　小屋 | 第一次走進屋裡 |
| 三　小房間 | 書櫃轉開，第一次走進後面的小房間 |
| 四　替身工作 | 在登記簿蓋章加入（不加入的人，這章跳過） |
| 五　最終選擇 | 第一個結局開始播 |
| 結束 | 試玩者說「玩完了」，或停下來不想再玩 |

## 玩完以後：提示用了幾次

在同一個分頁按 F12 打開開發者工具，到 Console 貼上這一行：

```js
JSON.parse(localStorage.getItem('holy-merry:cabin:v1')).hints
```

會列出每個謎題翻到第幾層提示，例如 `{ yard: 1, log: 3 }` 表示院子看了 1 層、交接表看了 3 層。也請記下來。

## 怎麼判斷要不要調整

- 某一章的時間超過目標的兩倍，或兩位以上卡在同一個地方：那裡的線索不夠清楚，要加強線索或提前一層提示。
- 某個謎題大家都翻到最後一層：謎題太難，或線索放的位置不容易被看到。
- 有人以為壞掉了：那裡少了「為什麼不能動」的回饋（字幕或動作）。
- 誤點、按錯：檢查點擊範圍與遮擋。
