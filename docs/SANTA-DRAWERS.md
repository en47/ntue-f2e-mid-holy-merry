# Santa：真的抽屜（書桌、音樂盒）

使用者回報（2026-11-12）：抽屜像貼上去的圖，不符合自然法則。

原本書桌和音樂盒的抽屜，是蓋在 3D 畫面上的平面圖片：
- 不跟著書桌的透視和厚度。
- 打開只是往下多出一條深色長條。
- 音樂盒的抽屜比盒子寬，還垂到下面的層板上。

## 現在的做法

兩個抽屜都是場景裡真的小抽屜盒（`js/components/cabin-scene.js` 的 `buildDrawer`）：
- **組成**：前板、底板（從上往下看的樣子）、兩片側板、背板，都是事先剪好的紙板。
- **位置**：嵌在家具紙板上畫成暗色的抽屜洞裡，跟著家具一起站、一起轉。
- **關著**：只看得到前板。其餘部分在家具裡面，而家具紙板上面的桌面是畫上去的、後面是空的，所以盒身先不顯示，免得從桌面上方透出來。
- **拉開**：盒子朝房間滑出，鏡頭略往下看，看得到抽屜裡的東西，家具上留下暗的洞。

| 抽屜 | 深度／滑出 | 前板的樣子 | 底板的樣子 |
| --- | --- | --- | --- |
| 書桌（`desk`） | 0.2／0.15 | 鎖著；鑰匙轉開後插在鎖孔上（`key`） | 放大鏡和吸墨器；放大鏡拿走後只剩吸墨器（`taken`） |
| 音樂盒（`musicbox`） | 0.062／0.042 | 黃銅卡榫卡著；撥針撥開後卡榫垂下（`undone`） | 紅絨布、音梳、尼爾斯的紙星星；找到後只剩音梳（`empty`） |

尺寸和位置寫在 `js/components/cabin-art.js` 的 `DRAWERS`。各片的樣子是 `cabin-paint.js` 的 `PIECES` 和 `VARIANTS`，事先剪在 `images/cabin/`。

## 遊戲怎麼接

- `cabin.drawer(id, { open, front, inside })`：開關抽屜，或換前板／底板的樣子。房間還沒載好時先記著。
- `cabin.drawerRect(id)`：前板目前在畫面上的位置。
- `.desk-drawer`、`.musicbox-drawer` 兩個按鈕只是蓋在前板上的點擊範圍，鑰匙、撥針、點開的玩法都照舊。
- 載入存檔時，`cabin-play.js` 的 `restore` 依存檔還原兩個抽屜的樣子。
- 音樂盒：抽屜先滑出來，音梳卡片才出現。寬螢幕上卡片放在音樂盒右邊，不擋住抽屜。
- 離開書桌或音樂盒時，開著的抽屜會推回去。

## 同一批回饋的其他修正

- 小房間打開小冊（或任何卡片）時，卡片上會點到後面的舊紀錄簿：上一階段為了讓舊紀錄簿蓋過分揀架，把它的層級調高，結果連卡片也蓋過去了。改成調整建立順序：舊紀錄簿只在分揀架上面，卡片仍然在最上面。
- 書桌左邊等著寄出的信：信封的一角從桌緣底下露出來。改成真的小信架，依序是後板、只微微傾斜的信封、扇形上緣的前板（擋住信封底部）、底座。
- 線索本最下面加了「從頭再玩一次」：先說明會清掉什麼並問一次，確定後只清聖誕村的進度（`holy-merry:cabin:v1`、`holy-merry:cabin:found`），重新整理回到第一章。Wish 等其他頁的資料不動。
- 手寫字型換成芫荽，見 `docs/HAND-FONT.md`。
