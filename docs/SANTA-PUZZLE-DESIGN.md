# Santa 第五頁：五章節解謎設計（Tiny Room 式）

> Santa was never just one person.　原來，聖誕老人從來不只是一個人。

這份文件是改造前的設計，**還沒有動任何程式**。確認後依第 12 節分階段實作，每一階段都能單獨驗收。

狀態標記：
- 【已有】已經存在於目前程式（`final` 分支）
- 【已定待做】邏輯已確定、尚未實作
- 【新增】需要新寫的功能或美術
- 【待確認】需要你決定，列在第 14 節

目標時間：第一次完整遊玩約 40～45 分鐘（各章估計值，需實際玩家測試）。熟手約 30 分鐘。只想逛一下的訪客，在第三章不加入、走出門就是結局 A（約 20 分鐘）。

## 1. 五章節流程圖

```
第一章　院子（約 8 分）　─ 先看到鎖，再找到開它的東西
  [郵筒] 打開 → 抽出信封 → 展開
         ├ 寄給聖誕老人的信
         ├ 照顧便條「別忘了餵馴鹿。上次輪到你時，牠可是等了好久！」（線索：輪班）
         └ 「給麋鹿的點心」→ 地衣【道具】
  [穀倉絞盤] 一開始就看得到少了把手＋維修標籤「下次使用前，記得把把手裝回去。」
  [雪人腳邊] 微微隆起的雪堆，露出一截木頭 → 撥開 → 木把手【道具】
  [餵食槽] 放進地衣 → 麋鹿低頭吃、身體挪開 → 乾草裡露出一點金色（不自動拿）→ 撥開 → 小鑰匙【道具】
  [穀倉] 裝上把手 → 轉絞盤（滑輪、繩索同步）→ 乾草升起 → 固定 → 乾草後的隱藏抽屜 → 拉開
         ├ 火柴盒【道具】
         └ 12/24 交接紙條（兩種筆跡）【線索】
  遠景伏筆：從院子看小屋左側，後方高窗透出微光
        │（可隨時進屋，順序自由）
第二章　小屋（約 10 分）　聖誕老人坐在搖椅上
  [壁爐] 火很弱 ←火柴→ 火旺、室內變暖 → 石板浮出 R 字刻痕；書櫃上四本書的金色書脊在火光下反光
  [書桌] 抽屜有鑰匙孔 ←小鑰匙→ 放大鏡【工具】＋搖擺式吸墨器（檢查模式翻面：反寫的「Look within our name.」）
         桌面：平安夜路線筆記（第四章用）、信的背面筆跡
  [音樂盒] 拖曳發條 → 紙雕升起，四個金色書脊形狀的裝飾
           盒底小抽屜被黃銅卡榫卡住（看得到小孔）→ 第三章取得撥針後可開（支線 N）
  [雪花球] 搖晃 → 雪沉澱 → 小屋門牌太小 ←放大鏡→ 看清；底座刻著 2003（放大鏡）
  調查 ≥ 2 樣 → 窗外麋鹿鈴聲 → 回到房間中央時聖誕老人外出：「哎呀，馴鹿好像又把飼料弄翻了！我出去看看。」
  → 搖椅上原本被擋住的紙條：「There's always room for more.」
  [書櫃] HOLY MERRY 九本書，M O R E 四本金色書脊略突出 → 拖曳排成 MORE SANTA → 木頭機關聲 → 書櫃旋開
        │
第三章　秘密工作室（約 8 分）　一進門主要東西全看得到，但要動手才懂
  名牌板（五個名牌：名字、代表色、工作標記；右邊空一個掛勾）、帽架（大小不一的帽子＋空位）、
  分揀架、水漬的交接表、替身守則、替身登記簿、紅繩綁著的舊紀錄簿（四位數轉盤）、郵戳章盤、鏡子
  [交接表] ← 名牌（顏色＋工作標記）＋麋鹿照顧紀錄（院子）＋12/24 紙條＋守則 → 推理補回 → 第一次反轉
  聖誕老人回來：「看來，你已經發現我們的小秘密了。」→ 介紹自願替身制度
  選擇：在登記簿簽名加入 ／ 繼續當訪客（可走出門 → 結局 A）
  [郵戳章盤] 黃銅撥針【工具】→ 回第二章打開音樂盒卡榫（支線，不擋主線）
  [舊紀錄簿] 可先注意；轉盤隨時可轉（允許提前發現 2003）
        │（加入後）
第四章　替身工作（約 12 分）　每件都是新的操作與思考
  登記簿你那一列夾著一張看似空白的特殊紙條【道具】
  ① 照顧馴鹿：穀倉牆上「12/25 餵食表」→ 依序餵食
  ② 裝載雪橇：書桌的平安夜路線 → 第一站的禮物放最上層（反序裝載）
  ③ 分信與回信：分揀架（郵戳時間 × 交接表）→ 回覆一封虛構信件
  ④ 修摩天輪：遊樂場雪地裡的特大齒輪【道具】→ 動力箱排齒輪、轉手柄
  做完任兩件：登記簿多出「加入年份」欄，H. 是 2003（和雪花球底座同一年）→ 疑點
  [特殊紙條] ← 壁爐旁被烘熱的石板（安全熱源，不放進火裡）→ 浮出「雪花球一直記得。」
  → 放大鏡看雪花球底座 2003 → [舊紀錄簿] 轉到 2003 → 第二次反轉（可選）
        │
第五章　最終選擇（約 5 分）
  四件工作都完成 → 聖誕老人：「你的工作已經完成了。想再看看這間小屋，還是準備繼續旅程呢？」
  ├ 繼續探索（不強制結局）
  ├ 帶著願望離開 → B　／　看過舊紀錄 → B＋真相
  └ 自願留下 → C（帽架空位掛上你的帽子）／ 看過舊紀錄 → C＋真相
  沒有加入、走出小屋 → A
  任何結局後：紙雕紀念明信片（可存成圖片）→ 回到 Home
支線：五位替身的見面禮（內容不變，不擋主線）
```

## 4. MORE SANTA 書櫃規則

答案不出現在任何一處；四件家具各給一個角度，合起來才指向 MORE：

| 來源 | 給的資訊 | 單獨看時 |
| --- | --- | --- |
| 壁爐火光 | 書櫃上有四本金色書脊在反光；石板有 R | 「書和字母有關」 |
| 書桌吸墨器 | Look within our name. | 「答案在我們的名字（HOLY MERRY）裡」 |
| 音樂盒 | 四個金色書脊形狀 | 「是四本書」 |
| 雪花球門牌 | 書櫃門的圖案【待確認 5】 | 「書櫃後面有東西」 |
| 搖椅紙條 | There's always room for more. | 「more」 |

金色書脊平常略突出、偏暗；壁爐點火後反光明顯（火光越旺越亮）。【已定待做】（這會改回前一版拿掉的燙金，但比原本更低調）

書櫃操作【已有】：拖曳抽出、吸附、交換、全部放回；手機可完成；只有 MORE 在 SANTA 左邊時啟動；成功時四本書發光、木頭機關聲、書櫃旋開，沒有「PUZZLE COMPLETE」。

提示四層（玩家主動要求才給）：
1. 這幾本書的裝訂似乎不太一樣。
2. 仔細看看 HOLY MERRY 裡哪幾個字母比較特別。
3. 那四個字母可以組成一個英文單字，放在 SANTA 前面。
4. 將 M、O、R、E 排在 SANTA 左側。

書櫃前目前的「找到的字母」紙片會拿掉（新設計不再收集字母）。

## 6. 2003 第二次反轉流程

1. **疑點**：加入後做完任兩件工作，聖誕老人把登記簿更新，多了「加入年份」欄：N. 2015、K. 2016、E. 2019、O. 2021、**H. 2003**。玩家若在第二章看過雪花球底座，會想起同一個數字。【新增】
2. **特殊紙條**：加入時登記簿自己那一列就夾著，看起來是空白的。【已有：改成加入時拿到】
3. **顯字**：放在壁爐旁被火烘熱的石板上（不是放進火裡），淡褐色的字慢慢浮出：「雪花球一直記得。」需要壁爐已點燃。【已有：改熱源】
4. **回到雪花球**：用放大鏡看底座 → 2003。【已定待做】
5. **打開舊紀錄簿**：轉盤 2003 → 紅繩鬆開。紀錄格式：
   - CHRISTMAS RECORD · 024
   - 名字、願望、狀態（WISH FULFILLED，SVG 墨水章）、日期 2003/12/24
   - 之後仍在工作：2003/12/25 送禮、12/26 修雪橇、12/27 準備新的信……以及之後每一年的夜班
6. **親筆便條**：「曾經有人讓我的聖誕節變得特別，所以我也想這樣做。」（Someone once made Christmas special for me. I wanted to do the same.）

不靠隱形章節鎖：轉盤任何時候都能轉，玩家提前推理出 2003 就讓他打開（例如第三章就打開）。後面的疑點、紙條只是給沒想到的人的引導。

## 14. 需要你確認的設計細節

1. **荷莉不改名**：規格裡的舊紀錄範例名字是 Noelle。目前名牌、帽子、雪花球、結局信都是荷莉（H.），願望是「讓住院的媽媽回家過聖誕節」。建議沿用荷莉，紀錄格式照規格（CHRISTMAS RECORD · 024、之後的工作日期、親筆便條）。
2. **許願與留下的規則**（目前：三個章可許願、四件工作都做完可簽早班；未經你同意不改）。建議維持不變：三個章就能在登記簿許願並選擇離開（B），四件都完成時聖誕老人才問最終選擇，可以選留下（C）。另一種做法是四件都完成才開放 B 與 C，但這會改變點數規則。
3. **結局 C 的標記**：規格是帽架空位掛上你的帽子；目前是名牌板第六個掛勾掛上你的名牌。建議兩個都保留。
4. **音樂盒卡榫的工具**：建議用工作室郵戳章盤上的「黃銅撥針」。打開後裡面維持原本的音梳與尼爾斯的吊飾（支線不變）；盒蓋內側多一行刻字「給 2003 年的新替身 H.」，作為通往舊紀錄的軟性線索，不是必要密碼。
5. **雪花球門牌的內容**：建議畫成「一扇藏在書櫃後面的門」的小圖示，呼應第一章的側窗微光，同時暗示書櫃，但不寫出 MORE。
6. **金色書脊回來**：前一版剛拿掉燙金，規格又要「略突出的金色書脊」。建議做得低調，平常偏暗，壁爐點火後才明顯反光。
7. **沒有署名的禮物、鏡子出現的時機**：建議禮物在四件工作都完成後出現在分揀架最上層，鏡子在看過舊紀錄之後才有反應；兩者都不影響結局。
8. **物件上的英文**：吸墨器、搖椅紙條、舊紀錄格式用英文（如規格），線索本裡附中文翻譯。
