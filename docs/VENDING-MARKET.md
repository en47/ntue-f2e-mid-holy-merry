# Vending 頁：黃昏雪地的聖誕市集

第五頁的主畫面。像 Santa 頁一樣，用紙板在 Three.js 裡立成 3D，照一張構圖擺放，一眼看完整個畫面。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `js/services/market-layout.js` | 每樣東西的位置。用構圖上的像素位置反推 3D 座標：地上的東西從腳的位置找到地面上那一點，再依頂端和左右算出大小；看不到腳的放在指定深度。純資料，`tests/market-layout.test.mjs` 檢查。 |
| `js/components/vending-plaza-art.js` | 市集的紙片美術。大部分直接用構圖的像素座標畫；木攤、燈泡、三角旗以公分畫正面，由場景立成 3D。 |
| `js/components/vending-scene.js` | 場景：把紙片切成圖片、立在指定位置；木攤、三角旗燈串、精靈、點燈。 |
| `js/components/vending-square-art.js` | 精靈的紙片（身體、會動的手、走路的腿、熱氣）。 |
| `js/components/vending-papercraft.js` | 販賣機的卡紙模型（`MACHINE.depth` 是機身深度）。 |
| `js/components/vending-advent.js`、`vending-advent-art.js` | 降臨曆小屋，也負責把三角旗燈串綁到左邊燈籠的支架上。 |
| `js/vending.js` | 頁面進入點；標題招牌的位置在這裡每一幀更新。 |

## 構圖與擺放

- 鏡頭：眼高 1.5 m、水平視角 60°，地平線在構圖的 y 425（構圖寬 1370、場景從 y 110 到 860）。
- 任何螢幕都看得到整張構圖的上下：垂直視角至少等於構圖的 35°（`FRAME_TALL`）。寬螢幕往兩側多看，高螢幕多看天空和地面。
- 構圖兩側還有延伸：左邊轉角木屋往外延伸，加一棵雪樅樹、禮物、雪堆；右邊一排三間木屋、一間斜放的熱可可攤、一棵雪樅樹、禮物、雪堆。天空、雪丘、星星燈串也一起加寬。21:9 的螢幕、拉近小屋或販賣機時，都看不到場景的邊（`tests/market-layout.test.mjs` 檢查）。
- 遠景是兩層有明暗的雪丘，樹成群種在丘頂，腳下有積雪，不再像漂浮在山上。左邊老城那兩棵漂在屋頂後面的樹已經拿掉。
- 販賣機轉 23°，只比「正對使用者」多轉幾度，所以大致朝向使用者，左側又看得到深紅色側面。側面看起來多寬，等於機身深度乘以多轉的角度，越正對側面越窄。所以機身做得很深（0.78 個單位，寬 0.5），測試要求側面至少有正面寬的兩成。
- 黑板立牌的角度跟販賣機相同，字用標題的字型（Mountains of Christmas，`StorySign`）。
- 木攤都斜放（比正對使用者多轉 25° 以上），每間由三片組成：正面、靠近使用者那端的側牆（朝右斜的在左端，朝左斜的在右端）、往外斜出的條紋雨棚。構圖右緣那間只有正面。
- 標題招牌在構圖的 [40, 128, 372, 272]：比之前小約一成、低一點，上緣的積雪在畫面頂端之下，右緣停在販賣機頂上的星星左邊。它和星星燈串放在同一個深度（7.5 m）。燈串從招牌右緣下方開始，`vending.js` 每一幀把招牌（HTML 標題）放到這個 3D 長方形在畫面上的位置，所以不論螢幕比例，兩者都連在一起。走近販賣機或小屋時，招牌會淡出。
- 三角旗燈串是真的 3D 垂線：一端綁在彩球攤遠端的前柱，另一端綁在降臨曆小屋左邊燈籠的支架，不會穿過任何東西。
- 三隻精靈：彩球攤前踮腳拿彩球、玩具攤旁喝熱可可、抱禮物從販賣機後面走出來，一路走到降臨曆小屋、繞到小屋正面後面才不見（兩端都有東西擋著，所以不必淡入淡出），再重來。

## 色彩與自然法則

- 大面積的紅只留給販賣機：前景禮物改成綠、米白、金色，右邊攤位的雨棚是綠白。
- 所有木攤都立體斜放，透視一致；最右邊那間也一樣，而且讓開小屋，拉近小屋時不擋。
- 雪會堆在人不會踩的地方：每間木攤的前緣和靠近使用者那端、小屋底座前都有積雪。
- 前景的樹、木箱、禮物都有落在地上的影子。

## 選取框

- 用滑鼠或觸控操作時，程式移動焦點（走近後的第一個按鈕、回到廣場的販賣機或小屋按鈕）不顯示外框；只有用鍵盤時才顯示。
- 蓋在販賣機和小屋上的按鈕不畫方框：鍵盤選到販賣機時招牌燈泡全亮，選到小屋時小屋亮起暖光。
- 廣場不能被選取文字（`user-select: none`），點按時沒有手機的藍色點擊底色。

## 不被裁切

- 立在場景裡的紙片，切圖前先量出實際畫到的範圍（`getBBox`）。雪、葉子、蝴蝶結畫出原本的框時，紙片會跟著放大，原本的框仍放在原位。
- 雪堆立在地上，底部會是一條直線，所以每個雪堆腳下會躺一片不規則的雪蓋住接縫。雪片的深度隨距離加大，遠處的雪堆也蓋得住。
- 不經過自動放大的圖（地面、地上的雪片、精靈各部位、標題招牌、小屋各部位），用瀏覽器量過都沒有畫出框外。
- 小屋右邊的斜屋頂：後端的雪是一團團圓邊；側邊的雪簷和簷下長度跟屋頂一樣，不再多伸出去。

## 操作

- 不能拖曳轉動，也不跟著滑鼠動。點販賣機或小屋時，鏡頭留在原地，轉向它並拉近；按 ✕、Esc 或點旁邊就回來。
- 頁面出現後，燈一盞盞亮起；減少動態時燈直接全亮，精靈靜止。
- 手機顯示同一幅畫面，寬度等於螢幕寬，高度是寬的 1/1.25。

## 頁尾

- 中間是紙雕抽選機（`js/components/foreground-toys.js` 的 `lottery`）：紅色八角轉盤加米白面、金框、方向箭頭、曲柄。
  - 點一下會自動轉一圈；也可以抓著轉盤繞著中心轉，只能往前，轉滿一圈就出球。
  - 球從轉盤下方掉出，滾進接球盤，接著跳出獎品：金球是金星（10%，會撒彩紙），紅、綠、白、棕分別是聖誕襪、聖誕樹、雪人、薑餅人，也就是販賣機賣的四樣。
  - 結果會用 `aria-live` 讀出；開啟減少動態時不轉，球和獎品直接出現。
- 左邊是市集的熱可可小推車（紅白雨棚、杯子冒熱氣）和一棵雪樅樹；右邊是工坊的蠟筆盒和一捲綁著紅緞帶的畫紙，加一棵雪樅樹（`js/components/page-foreground.js`）。頁尾高度加高，容得下抽選機。
