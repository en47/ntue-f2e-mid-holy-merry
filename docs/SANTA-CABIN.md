# Santa's Cabin（期末第五頁）

導覽列第五個吊牌「Santa」。聖誕節早晨，一棟正面切開的紙雕小屋坐在雪地上，像一頁立體書：屋裡的聖誕老人送完禮物回家，坐在搖椅上烤火。外觀參考使用者提供的剖面小屋照片：人字形瓦片屋頂、屋簷花圈、米白色切面、灰泥牆加木樑、綠色拱門、石頭壁爐、燈籠、聖誕樹。

> 演變：2026-11-07 第一版是頁面中間可以轉的立體盒；第二版改成整頁的室內房間；第三版（目前）改成雪地上的剖面小屋，加上「進屋」鏡頭。改的理由：參考圖的房子造型、麋鹿要站在屋外，以及不要和 Wish 的夜晚院子重複。

## 故事與時間線

- 導覽順序 Home（白天）→ Intro → Game（白天）→ Wish（平安夜）→ Santa（聖誕節早晨），時間一路往前。
- Wish 院子裡冒煙的小屋就是這棟房子。在 Wish 敲門，應門的角色會說「明天早上來屋裡坐坐吧」，並出現「明天早上來坐坐 →」吊牌連到本頁。
- 聖誕老人整夜送禮物，所以早上坐在搖椅上休息；之後的打瞌睡狀態也因此合理。

## 房子

- 內部：灰泥牆與木樑框架、護牆板；後牆是人字形山牆（圓窗、星星），綠色拱門、石頭壁爐的煙囪一路穿過山牆；左牆窗戶的窗台上放降臨小屋（12 月每天多亮一扇窗）；書櫃、檯燈與牛奶餅乾、聖誕紅地毯、聖誕樹與會閃的燈、從屋脊垂下的燈籠。
- 外部：瓦片屋頂（屋脊、屋簷積雪）、側牆木樑外牆與綠色百葉窗、米白色切面（牆、地板、屋頂）、屋簷花圈、煙囪與飄煙。
- 屋外：雪地底座、松樹、雪堆、郵筒、雪橇，以及麋鹿。
- 每片紙只畫成圖片一次，之後只移動 3D 物件；牆、地板、屋頂以 0.7 倍密度切貼圖，手機最低 0.5 倍。

## 兩種鏡頭

| 鏡頭 | 看什麼 | 怎麼進出 |
| --- | --- | --- |
| 屋外（預設） | 整棟房子與屋外，從屋脊上方往下看 | 拖曳左右轉動約 ±31°、上下 7°～29° |
| 屋內 | 推到聖誕老人面前 | 點聖誕老人、「走進屋裡 →」按鈕、在小屋上按 Enter；「← 回到屋外」或 Escape 離開 |

- 鏡頭位置、距離、視角平順過渡；減少動態時直接切換。
- 放開拖曳 1.6 秒後轉回正面。觸控只轉左右，直向手勢照常捲動頁面。
- 手機直式畫面以房子為準，麋鹿在左側畫面外，轉過去才看得到。

## 聖誕老人

- 頭跟著滑鼠轉，上限左右 0.24、上下 0.1 弧度，並由脖子分擔：2026-11-07 實測轉頭超過約 20°、低頭超過約 30° 時，帽沿會壓到眼睛、鬍子變形。
- 搖椅前後搖、上胸微微起伏；壁爐火焰、燈籠、樹燈與煙都會動，減少動態時全部靜止。

## Loading：排隊進小屋

- 隊伍依 `#cabin-stage` 的 `data-progress`（紙板 35%、聖誕老人 45%、麋鹿 20%）每 25% 走進一位，全部載完時門打開才淡出。
- 動畫全部內嵌 SVG；減少動態時角色直接站定。

## 出狀況時

| 狀況 | 呈現 |
| --- | --- |
| 聖誕老人模型下載失敗 | 房子照常出現，空搖椅旁貼紙條「我去餵麋鹿了，馬上回來！」 |
| 麋鹿模型下載失敗 | 屋外少了麋鹿，其他照常 |
| 瀏覽器不支援 WebGL | 顯示「3D 小屋暫時無法顯示」，背景與頁面其他部分照常 |

## 導覽列五個吊牌

- 手機選單一排掛五張，吊牌寬度 `min(78px, (100vw - 2rem - 16px) / 5)`；701～780px 縮成 70px。320～1440px 都不會超出畫面或壓到網站標誌。

## 之後要接上的

AI 對話（屋內鏡頭時出現對話泡泡）、聖誕老人打瞌睡等狀態、餵麋鹿（拿起食物時鏡頭轉向屋外的麋鹿）、點開降臨小屋。
