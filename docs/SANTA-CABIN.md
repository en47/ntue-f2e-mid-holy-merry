# Santa's Cabin（期末第五頁，樣品）

導覽列第五個吊牌「Santa」。整頁就是聖誕老人的小屋內部：每片紙板用全站同一套紙雕工法畫成圖片，再立進 Three.js 場景圍成房間，坐在搖椅上的 3D 聖誕老人在正中間。小屋撐滿導覽列以下的整個畫面，標題是從天花板垂下來的縫線木牌。鏡頭站在房間裡，拖曳可以環顧四周，放開後會慢慢轉回聖誕老人。

> 2026-11-07 第一版是放在頁面中間、可以轉的立體盒（有紅色正面框和牛皮紙外殼）；依使用者意見改成整頁的房間，不再有盒子外框與留白。

## 紙雕房間

- 房間從後牆（z = -0.9）一路延伸到鏡頭後方（z = 4），環顧時永遠看不到房間開口。
- 紙板：後牆（窗戶、窗台上的降臨小屋、花圈、相框、燈串）、左牆（窗戶、掛著紅大衣的衣帽架、通往雪地的門）、右牆（層架、雪鞋、堆滿信件的書桌、窗戶）、地板（編織地毯、門口地墊）、天花板（木樑與燈串）、聖誕樹、壁爐、火焰、小桌（牛奶與餅乾）、四片搖椅（椅背、兩片側面、扶手前端）。
- 每片紙只畫成圖片一次（`paperFilter` 的毛邊與紙紋），之後只移動 3D 物件；貼圖解析度依螢幕寬度縮放，手機最低 0.5 倍，牆、地板、天花板再降為 0.7 倍密度。
- 立著的紙板背後多一片同形狀的米白色剪影，轉頭時看得到紙的切邊。
- 降臨小屋有 24 扇窗：12 月每天多亮一扇，11 月全暗，其他月份全亮（`adventLit()`）。

## 鏡頭與操作

- 鏡頭繞著聖誕老人轉：橫向螢幕距離 3.6、視角 46°，直向手機靠近到 2.8、視角 60°，中間的比例平滑過渡；寬螢幕鏡頭稍微抬高，讓窗戶不被標題木牌擋住。
- 拖曳：左右最多約 ±22°，滑鼠上下可調 6°～19°；鏡頭永遠在牆、天花板與房間開口之內。觸控只轉左右，直向手勢照常捲動頁面（`touch-action: pan-y`）。放開 1.6 秒後慢慢轉回聖誕老人。
- 鍵盤：Tab 到透明的 `.cabin-gesture` 按鈕（「環顧小屋」），方向鍵轉動，Escape／Home 回正。
- 平常每秒約 30 格；拖曳與回正時全速。離開畫面或切換分頁就停止。

## 聖誕老人

- 頭跟著滑鼠轉（`createHeadTracker`），上限左右 0.24、上下 0.1 弧度，並由脖子分擔。2026-11-07 實測：轉頭超過約 20°、低頭超過約 30° 時，帽沿會壓到眼睛、鬍子變形，所以刻意縮小。
- 搖椅前後搖、上胸微微起伏當作呼吸、壁爐火焰閃動並照亮聖誕老人；「減少動態」時全部靜止，只在操作時重畫一次。

## Loading：排隊進小屋

- `site-loader.js` 的 `santa` 主題：雪地小路通到小屋門口，前面排著小精靈、企鵝、雪人、麋鹿，訪客拿著「No.5」號碼牌。
- 隊伍依 `#cabin-stage` 的 `data-progress`（紙板 35%、模型下載 65%）每 25% 走進一位，全部載完時門打開才淡出；不是固定動畫，網路慢就走得慢。
- 動畫全部內嵌 SVG，不需要下載；「減少動態」時角色直接站定，不走動。

## 出狀況時

| 狀況 | 呈現 |
| --- | --- |
| 模型下載失敗 | 小屋照常打開，空搖椅旁貼紙條「我去餵麋鹿了，馬上回來！」 |
| 瀏覽器不支援 WebGL | 顯示「3D 小屋暫時無法顯示」，頁面其他部分照常 |
| 載入超過 12 秒 | Loading 照全站規則結束，小屋載好後自己出現 |

## 導覽列五個吊牌

- 手機選單一排掛五張，吊牌寬度 `min(78px, (100vw - 2rem - 16px) / 5)`；701～780px 縮成 70px。
- 實測 320、360、390、430、701、740、780、820、860、900、1024、1280、1440px 都不會超出畫面或壓到網站標誌。
