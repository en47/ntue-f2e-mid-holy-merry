# Santa's Cabin（期末第五頁）

導覽列第五個吊牌「Santa」。聖誕節早晨的紙雕聖誕村：一棟完整的小屋站在中間，訪客站在屋前原地轉頭，左邊是遊樂場與許願角，右邊是冬天的海岸與燈塔，小屋後面是滑雪場。點小屋，鏡頭會走到門前、推開門走進去；屋裡的聖誕老人送完禮物回家，坐在搖椅上烤火，房間可以 360° 環顧。外觀參考使用者提供的小屋照片：人字形瓦片屋頂、屋簷花圈、灰泥牆加木樑、綠色門、石頭壁爐、燈籠、聖誕樹。

> 演變：2026-11-07 第一版是頁面中間可以轉的立體盒；第二版改成整頁的室內房間；第三版改成雪地上的剖面小屋，加上「進屋」鏡頭；第四版把圓盤底座換成延伸到遠山的雪地，並依自然法則整理光線、樹與頁尾；第五版（目前）把剖面封起來成為完整的小屋，加上可以走進去的門、360° 室內，以及小屋四周的聖誕村。

## 故事與時間線

- 導覽順序 Home（白天）→ Intro → Game（白天）→ Wish（平安夜）→ Santa（聖誕節早晨），時間一路往前。
- Wish 院子裡冒煙的小屋就是這棟房子。在 Wish 敲門，應門的角色會說「明天早上來屋裡坐坐吧」，並出現「明天早上來坐坐 →」吊牌連到本頁。
- 聖誕老人整夜送禮物，所以早上坐在搖椅上休息；之後的打瞌睡狀態也因此合理。

## 房子

- 內部：灰泥牆與木樑框架、護牆板；後牆是人字形山牆（圓窗、星星），綠色拱門、石頭壁爐的煙囪一路穿過山牆；左牆窗戶的窗台上放降臨小屋（12 月每天多亮一扇窗）；書櫃、檯燈與牛奶餅乾、聖誕紅地毯、聖誕樹與會閃的燈、從屋脊垂下的燈籠。
- 外部：四面都封起來。正面是灰泥木樑牆、石頭牆腳、綠色木門（門上花圈、兩側壁燈）、亮著燈的窗、山牆圓窗，另一側是柴火堆和靠在牆上的滑雪板；瓦片屋頂、屋簷花圈、煙囪與飄煙。窗戶是畫上去的暖光與窗簾，從外面看不進屋裡。
- 前牆內側：門的另一面（木板與鐵鉸鏈）、同一扇窗（窗外是雪景）、門邊的掛衣架（備用的紅外套、帽子、圍巾和靴子）、掛畫。
- 門洞同時切穿前牆的兩片紙，中間用細木框（門框、門楣）擋住牆的夾層；門是獨立的兩片紙背對背掛在左邊鉸鏈上，往外開，所以走進走出時門板不會掃過鏡頭。
- 房間深度從 2 加到 3（`HOUSE.depth`），站在屋裡才有轉身的空間；壁爐、書櫃都靠後牆，跟著後牆位置移動。
- 搖椅斜放在地毯上，正對進門後站的位置（`INSIDE.eye`），聖誕老人一進門就面向你；椅子先轉向再前後搖，搖的方向跟著椅腳。
- 後牆的綠色拱門是後門，通往後院的玩具工坊（屋外左後方那棟紅色長屋）；點它會說明，目前不能走過去。
- 屋外：一整片延伸到遠方的雪地（顏色就是頁尾的雪色）。左前方鐵架上掛著木招牌「Santa's Cabin」，下面是郵筒；左邊有雪人、柵欄與結冰的池塘；右邊麋鹿站在雪橇旁，一條雪地小路經過兩盞掛花圈的路燈與拐杖糖，通到紅色的馴鹿小屋；遠方地平線上是霧裡的小村莊與教堂。幾棵冷杉分成兩小叢，留出空間。

## 依自然法則

- 光線：太陽低掛在左上（全站的光源方向），影子落在物體右後方，帶一點雪地的藍色；屋外的鏡頭看得到地平線與天空。
- 空氣透視：山丘越遠越淡、越偏藍，最後融進晨霧（`scene.fog`）；遠山只比地平線高一點，不會擋住天空。
- 遠近：只放幾棵冷杉，近大遠小；遠山不畫樹林——遠到看不出單棵樹的森林，畫成小點只會變成密密麻麻的圖案（使用者回報有密集恐懼感），所以遠方只留起伏的雪丘。轉動時近物與遠山之間有真實的視差。
- 冷杉：五層圓潤的紙雕樹冠、下緣輕微起伏，積雪只壓在每層上緣，背光的右側較暗；樹會轉向鏡頭，從哪個角度看輪廓都乾淨。
- 風向：煙囪的煙與雪花都往右飄。
- 招牌與郵筒放在一起，麋鹿在雪橇旁、牠的蹄印沿著通往馴鹿小屋的小路；雪地有幾片很淡、很大的起伏陰影，避免一整片死白。
- 屋頂閃爍的原因是兩個面疊在同一個平面上（Z-fighting）：屋頂與牆的切面都退進板子之間一點，近裁切面也跟著鏡頭距離調整。

## 標題

- 看得到的標題是掛在房子左前角的木招牌，字形就是全站頁面大標題用的 `heading-glyphs`（`santas-cabin`），會跟著房子轉；`<h1>` 保留在 HTML 給讀屏與搜尋引擎（視覺上隱藏）。

## 頁尾

- 頁尾是同一片雪地往前延伸：`data-tone="snow"` 的白色雪丘只帶一點藍色陰影，冷杉用同一套畫法，冷杉、柴火堆、北極柱子、鈴鐺底下都有接地影子。
- 每片紙只畫成圖片一次，之後只移動 3D 物件；牆、地板、屋頂以 0.7 倍密度切貼圖，手機最低 0.5 倍。

## 聖誕村（原地環視）

訪客站在屋前同一個位置（`VIEWS.outside.eye`）原地轉頭，左右各 90°，不會繞著房子公轉。各區都放在正面視野（約 ±28°）之外，要轉過去才會出現：

| 方向 | 區域 | 內容 | 與其他頁的關聯 |
| --- | --- | --- | --- |
| 左 50° 起 | 許願角 | 掛滿封好信封的願望樹（只看得到信封背面）、紅色許願郵筒、畫滿心願塗鴉的留言板、禮物堆 | Wish：寫信、寄信、樹上掛信；不顯示任何人的信 |
| 左 60°～115° | 遊樂場 | 會轉的摩天輪（車廂保持直立）、立體旋轉木馬（紙紋貼圖的頂棚與底座、木馬上下起伏）、熱可可與薑餅攤、彩旗串 | — |
| 右 40°～110° | 海岸 | 海面（重複的海紋慢慢流動）、三道會晃的紙海浪、浪花邊、濕沙帶、礁石上的燈塔（柔和的旋轉光束）、帆船、海鷗、六國路標（國旗）、明信片看板 | Intro：世界地圖的六個國家 |
| 正後方 | 滑雪場 | 雪山、兩條滑雪道上有滑雪者滑下、纜車、山腳小屋與旗子；前面立著畫了飛行雪橇和配對卡片的看板 | Game：飛行雪橇與配對遊戲 |

- 雪山、滑雪者、纜車本身就畫成遠方的霧色，不再套霧。
- 小屋左前方的指路牌用圖示（摩天輪、雪山、燈塔）提示可以往哪轉。
- 點遊樂設施、燈塔、路標、看板會輕晃一下，畫面上方出現一句話（`PROPS`）；摩天輪、雪山這類會動的不晃。
- 村莊的紙板在第一個畫面出來之後才分批畫，不拖慢 Loading。

## 鏡頭

| 鏡頭 | 看什麼 | 怎麼進出 |
| --- | --- | --- |
| 屋外（預設） | 站在屋前約 11.5 的地方、接近平視，原地環視整座村子 | 拖曳左右各 90°（邊緣像紙一樣有一點彈性，放開彈回），滑鼠上下 1°～24°；快速撥動會順著慣性再轉一點 |
| 院子四個角落 | 郵筒、麋鹿、雪人、馴鹿小屋的小遊戲 | 點物件；「← 回到小屋前」或 Escape 回到原本看的方向 |
| 屋內 | 站在門內幾步、面向搖椅上的聖誕老人，360° 環顧，上下約 ±63° | 點小屋（或在場景上按 Enter）；點門口、「← 走出門外」或 Escape 離開 |

- 進場：Loading 淡出後，鏡頭從村子左上方的高空（看得到遊樂場、海岸、燈塔、雪山）用 5 秒降到屋前；拖曳、點擊、按鍵或按探索清單都會立刻落地。高空時霧變淡，整座村子看得清楚。所以村子的紙板改成和小屋一起在 Loading 期間畫好。從瀏覽器快取返回的頁面、減少動態時不飛。
- 進屋：轉向門口 → 走近 → 門往外打開 → 穿過門框 → 門在身後關上 → 轉向聖誕老人，約 3.6 秒。門關上之後屋外整個隱藏，不在牆後白畫。
- 出屋：轉回屋內 → 往後退出門 → 門在面前關上 → 退回屋前，最後面向進屋前看的方向。
- 減少動態時直接切到終點，門保持關著。
- 手機與桌機站在同一個位置，所以左右兩區在同一個方向；窄螢幕改用較廣的視角，並稍微往左看讓招牌入鏡。
- 觸控在屋外只轉左右，直向手勢照常捲動頁面；屋裡上下左右都交給場景（按「走出門外」回到網頁捲動）。
- 太陽是 DOM 背景，轉頭時跟著天空移動（`--cabin-turn`）。
- 屋裡可點：聖誕老人、書架、壁爐、聖誕樹、小桌、窗台、掛衣架，各回一句話（`ROOM_PROPS`）；目前只是提示，之後的互動從這些編號接上。

## 聖誕老人

- 頭跟著滑鼠轉，上限左右 0.24、上下 0.1 弧度，並由脖子分擔：2026-11-07 實測轉頭超過約 20°、低頭超過約 30° 時，帽沿會壓到眼睛、鬍子變形。
- 搖椅前後搖、上胸微微起伏；壁爐火焰、燈籠、樹燈與煙都會動，減少動態時全部靜止。

## Loading：踩著雪走向小屋

- 一個提著燈的小訪客在雪地裡一直往前走，背後的村子分三層用不同速度滑過（遠處雪山、中間的摩天輪／路燈／燈塔／冒煙的小屋、近處柵欄與腳印），雪花飄、煙囪冒煙，預告這一頁會看到的東西。
- 下面一排十個腳印依 `#cabin-stage` 的 `data-progress`（紙板 35%、聖誕老人 45%、麋鹿 20%）一格格踩亮。
- 會動的都是 HTML 圖層的 `transform`／`opacity`，瀏覽器交給合成執行緒播放；小屋在背後畫紙板、解模型時主執行緒很忙，動畫也不會停（舊版排隊動畫動的是 SVG 內部，加上只在每 25% 走一步，所以會突然停住）。每條背景放兩份同樣的圖、剛好滑過一份的距離，接縫看不出來。
- 減少動態時全部靜止，腳印照樣依進度變色。

## 院子探索（四個角落）

`cabin-art.js` 的 `SPOTS` 定義每個角落的點擊範圍與鏡頭位置，`cabin-scene.js` 負責點擊判定與鏡頭移動，`js/components/cabin-play.js` 放每個角落的小遊戲，`js/santa.js` 記錄找到的角落並點亮招牌星星（星星數量跟著 `SPOTS` 長度）。目前四個角落：郵筒、麋鹿、雪人、馴鹿小屋。第五頁原本樹上的紙雕小精靈已依使用者指示移除，Wish 的小精靈是另一套 3D 模型，與這頁無關。

## 戶外遊戲（一）：雪人換裝

- 點雪人，鏡頭走到雪人前（寬螢幕讓雪人偏左，手機往上抬）並停住不讓拖曳轉頭；右側（手機在下方）打開紙雕衣櫃，分頭部、頸部、臉部、手持四個抽屜，共 21 件配件（`js/components/cabin-wardrobe.js`）。
- 點一下（或按 Enter）配件，它就從抽屜飛到雪人身上並讓雪人晃一下；再點一次拿下，點雪人身上的配件也能拿下；「恢復原樣」回到只有胡蘿蔔鼻子。原本的拖曳依使用者決定取消，點選比較順。
- 手持位置涵蓋兩隻樹枝手：掃帚、拐杖糖、提燈、禮物拿在右手；手套是一雙，沿著樹枝的角度套在兩隻手的末端（袖口包住樹枝、手套蓋住指尖）。
- 做法：雪人紙板前面疊四張小紙片（`PLACES`，頭、頸、臉、雙手），跟著雪人一起擺動、轉身、鞠躬；每件配件第一次穿時才畫成貼圖，之後重複使用。雪人身上「拿下配件」的按鈕由這四張紙片投影到螢幕上的位置計算，鏡頭停穩或畫面大小改變時重算。
- 四個位置都穿上時雪人跳起來轉一圈、灑紙片彩帶，招牌點亮一顆星。三種搭配有彩蛋：聖誕帽＋小鬍子（「Ho ho ho」跳一跳）、馴鹿角＋紅鈕扣鼻子（學麋鹿蹦跳）、高帽＋領帶（紳士鞠躬）。
- 造型與觸發過的彩蛋存在 `holy-merry:cabin:v1`（`js/services/cabin-progress.js`，只在本機，不寫 Firebase），下次來雪人還穿著；之後的聖誕護照或故事可以讀同一筆紀錄。
- 音效（`js/components/cabin-sound.js`）用 Web Audio 即時合成紙張聲與小鈴聲，不下載檔案；只在右下角音樂正在播放時發聲，音量跟著音樂音量。
- 冒出來的愛心、Z、星星改成紙雕圖，不再用文字符號。

## 戶外遊戲（二）：麋鹿餵食

- 點麋鹿，鏡頭走到牠右前方（背景是穀倉與雪山）並停住；下方是食物籃（胡蘿蔔、地衣、薑餅）和五格「今天吃了幾份」的紙愛心。
- 食物拖曳時會跟著游標，麋鹿的頭跟著看；拖到嘴邊出現一圈暖光，放開就被吃掉（食物飛進嘴裡縮小消失，籃子裡隔一下補一份）。點一下或按 Enter 直接餵。
- 胡蘿蔔：咀嚼（頭稍低、快速小點頭）、冒一顆愛心、紙對話框「喀滋喀滋！」。地衣：開心地跳一下再連點頭、三顆愛心、「是地衣！我最愛吃這個！」。薑餅：頭轉開並輕搖，薑餅飄回籃子，「不要不要，這是聖誕老人的點心！」。
- 吃滿 5 份就吃飽了：跳一下、冒愛心說「吃飽了，謝謝你！」，籃子收起，招牌點亮一顆星；當天再來只會點頭說「今天吃飽囉，明天再來餵我！」，隔天（本機日期）才能再餵。份數存在 `holy-merry:cabin:v1` 的 `feed`。
- 嘴巴沒有骨頭：模型只有身體三節、頭部五節骨頭，嘴巴位置固定在耳後那節（Head_3）的局部座標 (0, −0.24, 0.14)，跟著點頭、轉頭移動；是從畫面上的紅鼻子與嘴角反推出來的。
- 所有反應只轉頭部骨頭、整隻抬起；不拉伸模型。原本規劃的睡覺狀態已依使用者決定取消：模型沒有眼皮，低頭睡覺卻張著眼睛很奇怪。
- 麋鹿正面朝向訪客站的位置（`REINDEER.turn`），平常會輕輕呼吸、重心左右移、頭微微飄動；滑鼠在場景上時（屋外與餵食畫面）頭會看向游標：取游標那條視線上、離螢幕 1.5 的點，讓牠看過去，所以游標在中間時牠正看著你；轉頭上限左右 0.6、上下 0.3。
- 指路牌移到小屋左前角，從站位看不會再擋住雪人或郵筒。

## 紙雕文字框

- Santa 頁所有文字框與按鈕（提示、操作說明、麋鹿對話框與小尾巴、餵食紀錄、衣櫃與抽屜分頁、配件格、回到小屋前、恢復原樣、信與收信按鈕、食物籃、探索清單、錯誤訊息）都改成撕紙邊、帶紙紋與落影的紙片，不再是平整的圓角方塊。
- 做法：`js/components/cabin-paper.js` 用全站的 `paperFilter` 畫六種紙（米白縫線紙、紅色標籤、淺色紙、選中的金縫線紙、木色紙、白信紙）和對話框尾巴，各畫一次成 120×120 的九宮格，交給 CSS 的 `border-image`。框多大，四個紙角都維持原樣，只有邊與中間延伸；文字往內收、每張紙微微歪一點。
- 紙片準備好後 `.cabin` 標上 `data-paper` 才套用；在那之前（或 JavaScript 失效）維持原本的樸素樣式。清除舊樣式的規則用 `:where()` 壓低權重，讓每種紙片都蓋得過它。

## 戶外遊戲（三）：穀倉滑輪

- 穀倉門左邊的牆面、屋簷下有木樑與鐵架吊著一個滑輪（`HOIST`、`hoistBracket`／`hoistWheel`／`hayBale`／`hoistToggle`／`hoistHatch`，都畫在穀倉紙板上一起轉向）。一股繩子吊著一捆乾草（平常放在雪地上），另一股垂下木頭握把。乾草平常擋住牆腳的小暗格。
- 點穀倉，鏡頭走到穀倉右前方停住。握把上有一圈發亮的抓取區和「往下拉 ↓」紙條：往下拖（或方向鍵上下），乾草升起的距離等於握把下降的距離，滑輪依放出的繩長轉動，兩股繩子隨時從滑輪邊緣接到握把與乾草，繩子會吱嘎響。
- 沒拉到頂就放手，乾草會因為重量越滑越快地掉回地上、咚一聲落地；拉到頂時出現「掛上掛鉤固定」，三秒內沒掛也會滑下來。掛好後牆腳露出暗格，點木箱打開一張紙條：「12/24 — 夜班交接」是一種筆跡，「完成 ✓」和簽名是另一種筆跡（顏色、大小、傾斜都不同，簽名用紙雕筆畫），是之後故事的伏筆。收好紙條點亮招牌星星；「鬆開滑輪 ↺」可以放下乾草重玩。
- 是否掛著、紙條是否讀過存在 `holy-merry:cabin:v1` 的 `hoist`；離開時沒掛鉤的乾草會回到地上。原本「把乾草拖上閣樓」的遊戲已被取代，閣樓改成固定畫著幾捆乾草。
