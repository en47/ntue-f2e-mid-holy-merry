## 定位基準

`tree-grove-left` 與既有左雪丘共用 left／width／bottom；容器比例 965:190 對應雪丘畫布。樹根的 bottom 指向雪丘內部的可見雪面，而非整個舞台的獨立百分比。

| 舞台寬度 | 左雪丘及樹群 left / width / bottom |
| --- | --- |
| >900px | 2% / 37% / 25% |
| 601–900px | 1% / 38% / 26% |
| ≤600px | 1% / 44% / 30% |

`tree-grove-front` 與既有前景共用定位矩形：桌面 left -3%、width 106%、bottom -1%、height 25%；手機 left -22%、width 144%、bottom 0、height 22%。樹群 z-index 12，雪坡 11；裝飾 pointer-events:none，角色點擊不受阻。

手機獨立樹基準寬度為 `clamp(82px,23vw,120px)`，兩前景樹相對該雪坡矩形 left 15.5%／right 16%，維持原 PNG 長寬比。CTA 保持在裝飾前面。

雪山、村落、雪丘、前景、角色本身的座標與舞台 clipping 規則均未變更。

## 展開時間

保留現有 rotateX、底部 transform-origin 與 reduced-motion 行為，只更改樹木延遲：左小樹 2.25 秒、中樹 2.35 秒、左前景大樹 2.75 秒、右前景大樹 2.90 秒。左雪丘約 2.20 秒完成、前景約 2.70 秒完成，樹木開始時已具備雪地支撐。
