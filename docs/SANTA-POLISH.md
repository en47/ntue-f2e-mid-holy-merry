# Santa 最終優化（第七階段）

依據：`docs/SANTA-PUZZLE-DESIGN.md` 第 12 節第 7 階段。範圍包括線索清晰度、拖曳手感、遮擋、觸控、提示、存檔恢復、節奏。

這一階段不改謎題、場景、鏡頭、模型和故事，只修「玩起來卡手」的地方，並補上找出這些地方的工具。

## 遮擋與觸控檢查

新增 `scripts/santa-audit.mjs`。設 `AUDIT=結果.json` 時，七支 Santa 驗收腳本在每個截圖時機檢查畫面上的按鈕與卡片文字：

| 問題 | 檢查方式 |
| --- | --- |
| small | 手機上手指點得到的範圍小於 44×44。從按鈕中間往外探，看不見的放大範圍也算 |
| covered | 卡片裡的按鈕被卡片以外的東西蓋住（口袋、線索本、返回鍵、音樂鈕……），或場景上的點擊區被別的點擊區蓋住 |
| text | 卡片上的字被卡片以外的東西蓋住 |
| outside | 按鈕跑出畫面左右 |

規則：
- 卡片打開時，後面的場景先不檢查。口袋、線索本、返回鍵照樣檢查，因為卡片開著時也要用到。
- 檢查卡的全畫面遮罩是刻意的，不算問題。

```sh
AUDIT=/tmp/audit.json WIDTH=390 HEIGHT=844 node scripts/check-santa-jobs.mjs
```

### 第一輪找到、已經修好的

- **手機上太小**：
  - 線索本按鈕：40×47，改成 44×52。
  - 「跳過」、檢查卡與線索本的「收好」「翻面」、願望選項：高度不到 44，改成至少 44。
  - 登記簿的結局章：32px，改成 44px。真相金星的高度也改成 44px。
  - 場景裡的小東西加了看不見的 44px 點擊範圍，畫面不變。包括：穀倉抽屜的火柴盒與紙條（26px）、絞盤標籤、壁爐木柴與熱石板、書桌抽屜。
  - 火柴盒和紙條在抽屜裡並排，各自往外側放大，不吃掉對方。
  - 動力箱的軸釘與齒輪：原本就有放大範圍，再放大一點。
- **重疊**：
  - 小房間的舊紀錄簿點擊區有一部分被分揀架蓋住：舊紀錄簿改到上面。
  - 書桌的火漆印、郵戳蓋到抽屜卡片：抽屜卡片改到上面。
  - 手機上線索本卡片的「收好」被音樂鈕蓋到一角：卡片在手機上限高，讓出底下。

修完以後的最後一輪：七支腳本、兩種尺寸，加上整套遊玩。
- 桌機剩 6 項，第一輪是 25 項。
- 手機剩 27 項，第一輪是 58 項；其中 11 項是書櫃的書。
- 剩下的全部屬於下面「保留不改」的情況。

### 保留不改

| 情況 | 原因 |
| --- | --- |
| 齒輪裝上軸釘後蓋住軸釘 | 點齒輪就能拿下來 |
| 籃子裡的木柴互相疊著 | 每根的作用都一樣 |
| 裝上把手後，把手蓋住絞盤與標籤 | 那時要轉的就是把手 |
| 名牌板、聖誕帽、餵食槽的點擊區有一部分在畫面外 | 鏡頭框位，照規格不改鏡頭；露出來的部分點得到 |
| 動力箱的軸釘在手機上約 41px，工具盒裡並排的齒輪互相擠到 | 動力箱在手機上很小，再放大會互相蓋住 |
| 口袋剛收到東西、跳一下的那一瞬間，超出左邊約 6px | 只在動畫的一瞬間 |
| 書櫃 13 本書在手機上每本約 32px 寬 | 要改書櫃版面，列入第八階段 |

## 拖曳手感

口袋裡的東西拖到場景上：
- 手指放開的容許範圍從目標外 8px 放寬到 16px，滑鼠維持 8px。手指會擋住目標，常常差一點點。
- 先找正下方的目標，沒有才找旁邊的。所以放寬不會搶到隔壁的目標，例如緊鄰的爐火和熱石板。

## 提示

逐一核對線索本每個進度的提示：層數、最後一層有沒有給答案、內容是否和現在的玩法一致。

- 「替身工作」最後一層補上分信的答案（依寄出地：台北 E.、東京 O.、冰島 N.、多倫多 K.、奧斯陸 H.、開普敦 N.，北極的兩封給你），以及摩天輪動力箱裡也有自己的提示。
- 新增進度「再讀一次舊紀錄簿」（`reread`）。適用於先打開舊紀錄簿、後補好交接表的玩家：原本的提示還在教他們找密碼，現在改成提醒再讀一次，最後一層說明 2003 的意思。

## 存檔恢復

`RELOAD=1 node scripts/check-santa-playthrough.mjs` 會在六個地方重新整理頁面：院子、房間、書櫃、加入、三件工作、聖誕樹之後。每次都：
- 比對存檔一個欄位都沒變。
- 從院子接著玩下去，像玩家關掉頁面再回來一樣。

房間那一次也會檢查：重新整理後聖誕老人回到搖椅上，用過一樣東西、回到房間中間，他會再出門（第 9 節「誤離開或關掉頁面」）。

## 節奏

真人遊玩時間沒辦法自動量。`docs/SANTA-PLAYTEST.md` 是給 2～3 位沒玩過的人用的試玩記錄表，內容包括：
- 每章從什麼時候算起。
- 卡在哪裡、哪裡以為壞掉了。
- 從存檔讀出每個謎題用了幾層提示。
- 什麼結果代表要調整。

## 第八階段 UI 精修清單（目前累積）

- 手機上口袋會稍微擋到長卡片（不擋必要文字與按鈕；不移除放大鏡拖曳）。
- 熱石板顯字時，頁面會往上捲一點。
- 手機上麋鹿讓到旁邊後，有一部分在畫面右側外面；餵食槽的點擊區有一部分在畫面左側外面。
- 手機上明信片圖片偏小，要存成圖片才看得清楚。
- 手機上書櫃的書每本約 32px 寬，小於 44px。
