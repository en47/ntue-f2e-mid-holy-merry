# Santa 第五頁：故事線

> 原來，聖誕老人從來不只是一個人。

聖誕節早晨的北極小村。訪客一開始只是來玩：替雪人換裝、餵麋鹿、走進聖誕老人的小屋。慢慢地，他發現這裡的「聖誕老人」好像不只一位；最後，他可以自己決定要不要成為其中一個。

劇情進度全部由固定規則決定（`js/services/cabin-story.js`，有 node:test），聊天不能改變任何進度。所有信件、名字都是虛構的，不讀取 Wish 頁訪客的真實信件。

## 五個階段

1. **自由探索（院子）**：雪人換裝、餵麋鹿、穀倉滑輪、郵筒裡聖誕老人的信。每一樣都可以單純玩，但都藏著一點不對勁（見下方線索表）。
2. **走進小屋**：壁爐添柴與風箱、回信桌（讀小朋友的信、翻面看是誰處理的；替聖誕老人把給小米的回信封口、蓋郵戳、投進郵袋）、音樂盒、雪花球。玩過兩樣，聖誕老人說要去看麋鹿，出門了；搖椅上留了一張紙條。
3. **MORE SANTA 書櫃**：搖椅上的紙條是謎題：「這屋子裡，我最喜歡的四樣東西上，各藏著一個字母。把它們排在我的繪本前面，你就會知道這間屋子的小秘密。」四樣東西各藏一個字母：壁爐前的石板刻著 R（火燒起來，刻痕才被照亮）、書桌中間抽屜裡的搖擺式吸墨器印著反過來的 E（點一下翻正）、音樂盒轉起來時底下升起金色的 O、雪花球落定後小屋門牌上是 M。書背沒有任何標記；找到的字母會排在書櫃前的紙片上（照找到的順序），要自己排成 MORE，把那四本書搬到 SANTA 繪本左邊，四本書一起發光，書櫃轉開，後面是一間小房間。
   - **第一次反轉**：名牌（五個人）、夜班交接表、替身守則。交接表被雪水弄濕了，要先補回來：四個晚上各分前半夜、後半夜，暈開的格子還看得出墨水顏色（對照名牌上每個人的顏色），整個洗掉的三格要靠別處的線索（12/21 後半夜：麋鹿柵欄的照顧紀錄；12/24：穀倉暗格紙條的藍、綠兩種筆跡）。點一格再點名牌補上縮寫，填完只會說「有幾格對不上」，補對了墨水一行行乾回來，才算讀過。三樣都看過：「原來，聖誕老人不只一位。」回到房間，聖誕老人推門回來：「看來你都看見了。呵呵，這是我們村子的小秘密。」
4. **自願加入**：登記簿最新一頁的最下面空著一格。選一個字母當縮寫、蓋章，就成為替身；不加入也沒關係，加入後也隨時可以離開（章會留著）。四件替身工作，各在第一次完成時蓋一個章（之後都能再玩）：
   - 照顧麋鹿：餵牠最愛的地衣。
   - 收好乾草：穀倉滑輪把乾草拉上去掛好。
   - 處理信件：先到小房間的分揀架分信：八封信放進 N、K、H、E、O 和你的六個格子，守則是「信交給郵戳上那個時間正在飛的人；過了午夜，還算前一晚」，要對照交接表（例如 12/22 02:40 是 12/21 後半夜的 O.）。分錯的會被退回；分好後，給新替身的托馬、阿雅兩封送到書桌：挑一句話回信，署名「替身 J. 代筆」，封口、蓋郵戳、寄出。
   - 修摩天輪：加入後遊樂場的摩天輪停了；打開動力箱，從雪地裡找回特大齒輪，排出一串剛好咬合的齒輪，轉動曲柄。
5. **第二次反轉與結局**（下一節）。

## 兩次反轉

- **第一次：聖誕老人不只一位。** 名牌、守則讀過，弄濕的交接表也補對時揭曉（交接表：12/21 E.→O.、12/22 N.→K.、12/23 H.→N.、12/24 K.→H.）。
- **第二次：有人的願望早就實現了，卻還是留了下來。** 加入後做完兩件工作，登記簿的紅繩鬆了，卻被一個四位數的小鎖扣著；繩上夾著一張聞起來有檸檬味的空白紙條。拿到壁爐前、火燒到兩根柴那麼旺時靠近火，浮出荷莉的字：「我的願望實現的那一年，雪花球一直記得。」密碼就是雪花球底座的 2003。打開後翻到 2003 年的舊頁：荷莉的願望「讓住院的媽媽回家過聖誕節」，蓋著 WISH FULFILLED；之後每一年，她都在夜班上。不說教，只讓你自己看見。回到房間，聖誕老人會說：「她呀，是我們這裡最可靠的人。」

## 結局

| 結局 | 怎麼到達 | 內容 |
| --- | --- | --- |
| A　普通訪客 | 這次造訪看過登記簿的空格，沒有加入就走出門 | 聖誕老人送你到門口，塞給你一張明信片；登記簿最下面那一格永遠留給你 |
| B　願望旅人 | 集到三個章，在登記簿許一個願（守則：集到三個章，就能許一個願望） | 坐雪橇繞村子、下一場大雪、樹下寫著你縮寫的禮物、把祝福交給熱氣球；由另一位替身實現，留下一張他筆跡的字條 |
| C　自願留下 | 四件工作都做過，在交接表 12/25 早班簽名 | 早班寫著你；名牌板第六個掛勾掛上你的名牌 |
| D　真正的聖誕奇蹟 | 看過舊頁，再走到 B 或 C | 荷莉的信。許了願又留下來的人，信裡會說：「你和我一樣：願望實現了，還是留了下來。歡迎你，聖誕老人。」 |

每個結局達成時就記下，登記簿下方蓋著看過的結局 A～D，點章可以再看一次。所有結局都不是失敗。

### 結局劇場

每個結局是一齣全螢幕的紙雕小劇場（`js/components/cabin-ending.js` 舞台、`cabin-ending-art.js` 紙片、動作寫在 `css/santa.css`）：整頁變暗，立體書的天空、山、村子、前景雪地一層層從下面立起來，慢慢平移出景深；旁邊的紙上，標題是落下來的英文紙片字（`scripts/build-title-glyphs.mjs` 的 `ending-a`～`ending-d`），中文一個字一個字寫出來。約 15～20 秒，「跳過」或 Esc 直接到最後一格，播完有「再看一次」「回到村子」（後面接著 D 時是「繼續」）；減少動態時直接是最後一格的靜態畫面。網站音樂關著時，音樂盒輕輕播一段，播完慢慢停下。

| 結局 | 標題 | 畫面 |
| --- | --- | --- |
| A | Going Home | 傍晚，聖誕老人在小屋門口揮手；你提著燈籠沿雪地小路走向遠方的家，身後留下腳印；明信片飛到你面前；遠方的家亮燈、第一顆星出來 |
| B | Wish Granted | 夜裡，雪橇從右邊遠處的北極（紅白條紋柱）沿一路金色小星星載你回家；窗戶亮起來，裡面是你許的願（玩具雪橇／大雪花／金星／一封信），門上別著替身的字條（大雪的願望真的下大雪，祝福的願望有熱氣球飛走） |
| C | Staying On | 天慢慢亮，你的名牌晃進名牌板第六個掛勾；禮物袋丟進雪橇，其他五位圍著跳著送你，雪橇往太陽飛；旁邊寫下「12/25　早班　你的縮寫」 |
| D | Christmas Miracle | 夜裡，N、K、H、E、O 和你的名牌在花圈上一個一個亮起來；光從小屋門口傳到村裡每一扇窗；旁邊是荷莉的信，最後慢慢寫出「原來，聖誕老人從來不只是一個人。」 |

天上的雪是一顆顆紙片圓點（不規則邊、紙紋、一點陰影），六角剪紙雪花只在前景點綴幾片。

**彩蛋**：知道秘密後替雪人穿上聖誕老人裝，交接表的 12/25 早班會出現「雪人？（實習）」。

## 撕碎的舊照片（支線）

2003 年的一張舊照片被撕成五塊（`js/components/cabin-photo.js`）：小時候的荷莉戴著最小的那頂聖誕帽，抱著剛回家的媽媽，門邊一只行李箱，窗外下雪，小聖誕樹，角落白墨水寫著 2003。碎片藏在村子各處，存檔 `pieces`：

- 分揀架：信分好以後，最舊的信封裡滑出一棵掛著星星的小聖誕樹。
- 音樂盒底的小抽屜（知道秘密後才出現）：抽屜上刻著「照我們那一季飛的順序，彈一次」，五根刻著縮寫的音梳照交接表上大家第一次飛的順序彈（E、O、N、K、H，音高剛好是一串四度 E A D G C），抽屜彈開，裡面是下著雪的那扇窗。

## 線索本與分段提示

畫面右上角的牛皮紙小筆記本（`js/components/cabin-notebook.js`）：看到可能有用的東西時自動記下（穀倉暗格的紙條、信的背面、平安夜路線筆記、音樂盒蓋、雪花球底座、許願角留言板、名牌、守則……，文字在 `js/data/cabin-clues.js`），筆記本跳一下、亮紅點。翻開後下方有「卡住了？給我一點提示」：依故事目前卡在哪裡（`cabin-story.js` 的 `goal`）給提示，每按一次更明白一點，最後一句直接說怎麼做；按過幾次會記在存檔（`clues`、`hints`）。第一次記下線索、或聖誕老人出門後才出現。

## 推進提示

故事不靠任務清單推著走，只在每個段落結束時給一句話：知道秘密後「登記簿最新的一頁，最下面好像還空著一格」；蓋第二個章後「紅繩好像鬆開了一點」；第三個章「可以許一個願望」；第四個章「12/25 早班還空著」。

## 美術

故事裡的每樣東西都是同一種紙雕 SVG（紙紋、剪裁的紙邊、紙片陰影）：小屋與小房間的紙板事先畫好；疊在畫面上的卡片、信紙、信封、登記簿、舊頁、願望場景與結局劇場由 `cabin-paper.js`、`cabin-finale.js`、`cabin-ending-art.js` 用同一個紙張濾鏡畫出。蓋上去的東西（郵戳、收件章、登記簿的章、WISH FULFILLED）是墨水：同樣的紋理與不規則的邊，但沒有紙邊與陰影。按鈕是素面紙片。
