# Santa 第四章：替身工作（第五階段）

依據：`docs/SANTA-PUZZLE-DESIGN.md` 第 12 節第 5 階段。

加入以後，登記簿列出四件工作，順序自由，每件第一次完成時蓋一個章。每件都有自己的解謎操作；做完以後，場景會一直保持完成的樣子。工作 id 沿用舊的（`lichen`、`hay`、`letters`、`wheel`），舊存檔已經蓋過的章照算。

## 四件工作

### 照顧麋鹿（`lichen`）

- **線索在哪**：穀倉門上貼的 12/25 餵食表，時間沒照順序寫：
  - 07:30 胡蘿蔔
  - 06:00 北極燕麥餅
  - 09:00 地衣
  - 另註：薑餅不給。
- **怎麼解**：在麋鹿那裡，照時間順序餵：燕麥餅 → 胡蘿蔔 → 地衣。順序錯了，麋鹿會搖頭，要從頭再來。這次餵食不算進每天五份，所以麋鹿當天吃飽了也能做。
- **完成以後**：餵食表上的三格打勾。

### 裝載雪橇（`hay`）

- **線索在哪**：書桌的平安夜路線：台北 → 東京 → 雷克雅維克 → 多倫多。
- **怎麼解**：點麋鹿旁的雪橇，打開裝載卡。規則寫在卡上：貨架很窄，袋子只能一袋疊一袋，每一站只拿得到最上面那一袋。所以要由下往上裝：多倫多、雷克雅維克、東京、台北。照路線順序裝，會被退回來。
- **完成以後**：雪橇一直是裝好的樣子。

### 處理信件（`letters`）

- **怎麼解**：分揀架照舊，看郵戳的時間對照交接表。分好後，交給你的兩封信送到書桌，挑一封回覆、寄出就完成；另一封可以自己選要不要回。
- **完成以後**：分好的信留在架上，回信算已經寄出。

### 修摩天輪（`wheel`）

- **線索在哪**：加入後摩天輪會停下。打開動力箱，工具盒裡少了最大的齒輪，箱子旁邊的雪地裡有東西在發亮。
- **怎麼解**：先撿起特大齒輪收進口袋，拖回動力箱，它就留在工具盒裡。之後照舊排齒輪、轉曲柄。
- **完成以後**：摩天輪恢復轉動，特大齒輪一直留在動力箱裡。
- 修好後可以再打開動力箱排另外兩種盤面，但只有第一次蓋章。

穀倉的絞盤不再是替身工作：乾草照樣可以鬆開、再吊起來，只是不蓋章。

## 空白紙條與熱石板

- 紙條在哪：加入後，夾在登記簿你那一列。拿起來就收進口袋。
- 怎麼用：放在壁爐前被火烘熱的石板上，才會浮出「我的願望實現的那一年，雪花球一直記得。—— H.」。
- 放錯不會用掉，紙條彈回口袋：
  - 拖進火裡：字幕說紙條會燒掉，石板剛剛好。
  - 壁爐還沒點：字幕說石板是冷的。

2003 舊紀錄的判定沿用第 4 階段：
- 舊紀錄簿隨時轉得開。
- 交接表補對以後讀，才是第二次反轉。
- 加入前就開過的玩家，烤出字時字幕會說「你已經知道了」。
